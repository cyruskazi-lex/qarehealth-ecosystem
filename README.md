# Qäre Health

A sovereign health information exchange for emerging markets. Twelve persona
products on one shared record, with verified health impact that is measured,
signed, and tokenised so institutional capital can fund it.

The health instrument in the iQuantile / Lexington ecosystem, a sibling to
**Helios** (energy) and **Stratum** (mining), on the same Meridian design system
and the same Global Impact Commons.

## Layout

```
index.html                     the ecosystem landing page (Meridian, static)
assets/tokens.css              the one place colour and type tokens live
docs/PLAN.md                   the phased build plan
docs/product-registry.json     the twelve products: persona, pathway, demo entity
docs/impact-tokenization.md    the EESG Health Impact to capital model
products/<key>/                one static prototype per product (built in phases)
```

## Run

Open `index.html` in a browser, or serve the folder as static files. There is no
backend and nothing to install; everything seeds in memory. Deployable to GitHub
Pages or any static host as-is.

## The spine

Qäre HIE (the exchange) · Telos (context model) · EESG Health Impact (the
framework) · Global Impact Commons (verified, tokenised outcomes) · IRIS (the
agent). See `CLAUDE.md` for the full canon and build rules.
